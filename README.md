# LATCH: matrix-free lattice fusion of learned dual certificates

Research artifact for **Matrix-Free Lattice Fusion of Learned Dual Certificates**, Shivam Gupta, 17 October 2026.

LATCH maximizes a linear score over the coordinatewise min/max lattice generated by input vectors. If the inputs share a feasible region closed under those operations, the output stays feasible. For assignment duals the coordinates must be `(u, -v)`, not `(u, v)`.

The implementation does not receive the assignment cost matrix during fusion. The threshold-pattern cut graph has at most `min(d*(K-1), 2**K-2)` pattern nodes. Lattice normal forms, maximum-weight closure, dual warm starts, and prediction portfolios are established foundations; the paper distinguishes them from this particular construction and evaluation.

## Results and scope

- 4,096 exhaustive binary fusion cases and 400 random integer cases agree with independent lattice enumeration.
- 500 separate assignment instances / 3,000 solver starts agree with SciPy.
- 4,320 held-out generated assignment instances / 47,520 starts attain the same exact optimum.
- Eight-hint fusion strictly improves 4,037 best-input certificates and ties on 283. Family/regime reductions in mean initial dual gap are 5.81–20.02%.
- The current reference pipeline is **2.10 times slower at the median** than best-feasible-member selection after including aggregation overhead. This is not a production speedup claim.

The theory does not certify an incorrect upstream hint, optimize all feasible coordinate-menu combinations, guarantee faster search trajectories, or establish absolute novelty or patentability. Experiments use small synthetic distributions and prototype predictors. See the manuscript for precise assumptions, proofs, counterexamples, related work, and limitations.

## Reproduce

From this directory:

```bash
# Independent bounded enumeration, exact solver checks, regression cases.
python3 tests/verify.py

# Recreate all held-out inputs and check hashes, optima, and fusion bounds.
python3 tests/replay_retained.py

# Rebuild tables and four figures from retained raw outputs; no retraining.
python3 src/analyze.py

# Full fixed experiment: 6,480 training and 4,320 held-out assignments.
python3 src/experiment.py --train 240 --test 80 --sizes 16 32 64 --seeds 3

# Separate fusion-only scaling measurements.
python3 src/scaling.py

# Rebuild the standalone paper (Tectonic must be installed).
tectonic -X compile paper/main.tex --outdir paper
```

The full experiment overwrites generated result files. Retained compressed results are used by analysis unless a newly generated `results/raw.jsonl` exists. Rerun analysis after experiments to update tables and plots. Integer outcomes and input cost hashes should reproduce with the recorded environment; timing values are host dependent. Main timings were taken once in a fixed policy order and are descriptive.

Training samples, matched tests, and shifted tests are drawn in that order from each configuration's generator. The seed is `1720406 + 100000*bank + 100*n + family_code`, where family codes 1/2/3 denote block/spatial/IID. K-means uses ten initializations and random state 1720406. All policies share each test matrix; test optima do not enter training, completion, selection, or fusion.

## Minimal use

```python
import sys
sys.path.insert(0, "src")
import numpy as np
from latch import fuse, expression

z = np.array([[1, -2, 0, -1], [-2, 1, -1, 0]])
a = np.array([1, 1, -1, -1])
result = fuse(z, a)
assert result.value == 2
assert np.array_equal(expression(z, result.selected_masks), result.vector)
```

The integer reference backend rejects unsafe arithmetic and flow capacities at or above `2**30`; it supports at most 20 predictors. The mathematical theorem permits rational inputs and is not subject to these particular backend limits.

## Files

- `src/latch.py`: fusion, expression reconstruction, feasible completion, and readable exact Hungarian solver.
- `tests/verify.py`: independent lattice enumeration, signed/negative-cost cases, metamorphic checks, and explicit limitations.
- `tests/replay_retained.py`: independent regeneration of all 4,320 held-out inputs and checks of 47,520 retained records and 12,960 fusion bounds.
- `src/experiment.py`: training and held-out evaluation, including all eleven starts.
- `src/scaling.py`: repeated fusion-only measurements.
- `src/analyze.py`: all numerical summaries, tables, and scientific figures.
- `results/raw.jsonl.gz`: all 47,520 retained run records, including per-instance input SHA-256 hashes.
- `results/prototypes.npz`: all 27 frozen eight-prototype banks.
- `results/summary.csv`, `policies.json`, `headline.json`: reported descriptive results.
- `results/runtime_counterexample.json`: exact four-by-four nonmonotonicity witness.
- `paper/main.tex`, `paper/main.pdf`: editable source and the manuscript, including four vector figures.
- `SHA256SUMS.txt`: hashes of the retained artifact files.

The reference Hungarian code is intended to expose correctness and search effort. SciPy's compiled Jonker–Volgenant solver is much faster at the tested sizes and is retained as the exact reference. No external datasets, paid APIs, or model downloads are needed.
